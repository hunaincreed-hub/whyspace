# WHYspace

WHYspace is a lightweight, responsive text generator starter project. It runs entirely in the browser and needs no installation or API key.

## Run it

Open `index.html` in any modern browser.

## Structure

- `index.html` — application markup
- `assets/css/styles.css` — responsive styling
- `assets/js/app.js` — generator behaviour

The generator currently uses a local response engine. Replace `generateResponse()` in `assets/js/app.js` later when you are ready to connect an AI API.
